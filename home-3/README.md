# Hover Business Services — Website

Next.js 16 (App Router) + Tailwind v4 + GSAP/ScrollTrigger + Lenis smooth scroll.

## Run
```bash
npm install
npm run dev
```

## Structure
- `src/app/page.tsx` — home page
- `src/components/home/*` — home sections
- `src/components/layout/Header.tsx | Footer.tsx`
- `src/data/home.ts` — all site content/copy
- `src/styles/globals.css` — design tokens (ink + acid lime + violet)
